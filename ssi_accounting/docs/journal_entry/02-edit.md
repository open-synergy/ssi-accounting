# Edit Journal Entry

## Pre-Condition

- Record is in **Draft** status.
- User has _Can Edit Journal Entry_ access right (belongs to the Accounting User group
  or higher).

## Flow

1. Open the **Accounting > Journal Entries** menu.
2. Find and open the Journal Entry record to edit.
3. Change the required fields.
4. Click **Save**.

## Post-Condition

- The record is updated with the new values.

## Note

- Only entries in **Draft** status can be edited. Once an entry is **Posted** or
  **Cancelled**, the header fields and the **Journal Items** tab become read-only. To
  edit such an entry, reset it to Draft first — see
  [Unpost Journal Entry](05-unpost.md).
