# Delete Journal Entry

## Pre-Condition

- Record is in **Draft** status.
- User has _Can Delete Journal Entry_ access right (belongs to the Accounting User group
  or higher).

## Flow

1. Open the **Accounting > Journal Entries** menu.
2. Select one or more records to delete (check the checkbox).
3. Click **Action** > **Delete**.
4. Click **OK** to confirm.

## Post-Condition

- The selected records are permanently removed from the system, together with their
  journal items.

## Note

- A posted entry must never be deleted — it carries a statutory number. Cancel it
  instead; see [Cancel Journal Entry](10-cancel.md).
